# Dog API - 犬の画像取得アプリ

Dog APIを使用してランダムな犬の画像を取得・表示するシンプルなWebアプリケーションです。

## 機能

- ボタンをクリックするだけでランダムな犬の画像を取得

## 使い方

1. `index.html`をブラウザで開きます
2. 「画像を取得」ボタンをクリックします
3. 犬の画像が表示されます

## ファイル構成

- `index.html` - メインのHTMLファイル
- `style.css` - スタイルシート
- `script.js` - Dog APIから情報を取得するJavaScriptコード

## 技術スタック

- HTML5
- CSS3
- JavaScript (Fetch API)

## 使用しているAPI

- Dog API: `https://dog.ceo/api/breeds/image/random`
